# Вариант №9: Учет потенциальных клиентов

Разработан модуль регистрации потенциальных клиентов на базе HTTP-сервера `HttpListener`.

## Реализованные маршруты:
1. **GET /leads** — вывод клиентов с фильтрацией по источнику (`source`) и имени (`name`, без учета регистра).
2. **GET /leads/details?id=1** — подробная информация о клиенте.
3. **POST /leads/create** — создание клиента из HTML-формы (возвращает статус 303 See Other).
4. **PUT /leads/update?id=1** — обновление данных клиента (возвращает статус 204 No Content).

## Технические условия:
- Данные хранятся в оперативной памяти.
- Валидация имени: от 2 до 60 символов.
- Статус при создании всегда `new`.
- Безопасное кодирование HTML (`WebUtility.HtmlEncode`).
- Написаны тесты MSTest (проверка бизнес-логики).
